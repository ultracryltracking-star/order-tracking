📝 Data Setup Instructions

To connect this dashboard to your Google Sheet:

  1. Create a Google Sheet with these exact column headers in row 1:
Order Number | Shipped | Date Shipped ORD-001 | 1 | 2024-01-15 ORD-002 | 0 | ORD-003 | 1 | 2024-01-16
  1. Publish your sheet to the web (File → Share → Publish to web)
  2. Copy the published URL and update the SHEET_URL variable in the code
  3. Use 1 for shipped orders, 0 for pending orders
  4. Leave Date Shipped blank for pending orders
